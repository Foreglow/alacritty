# Foreglow — Alacritty Theme

## Installation

1. Copy `foreglow.yml` to your Alacritty config directory:
   ```bash
   cp foreglow.yml ~/.config/alacritty/foreglow.yml
   ```

2. Add the import to your `alacritty.yml`:
   ```yaml
   import:
     - ~/.config/alacritty/foreglow.yml
   ```

3. Restart Alacritty.
