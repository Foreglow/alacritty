## Installation

1. Copy `foreglow.toml` to your Alacritty config directory:
   ```bash
   cp foreglow.toml ~/.config/alacritty/foreglow.toml
   ```

2. Add the import to your `alacritty.toml`:
   ```toml
   [general]
   import = [
     "~/.config/alacritty/foreglow.toml",
   ]
   ```

3. Restart Alacritty.
